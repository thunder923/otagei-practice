⬇ 録画を保存

カメラ映像は端末内だけ・外部送信なし。iPhoneは HTTPS（非公開の置き場）か Macのローカル起動で開いた時にカメラが使えます。公開用には作っていません。ファイル直開きだとブラウザがカメラを止めることがあります。

履歴・ライブラリ 1回使ったら自動保存 / 曲名・グループで管理（端末内のみ）

使い方のコツ（地下芸想定）

1. Xの VideoStar オタ芸部とか、YouTubeの地下芸動画のURLを貼る
2. 曲名とグループ名を付けてライブラリ保存 → 次からワンタップ
3. YouTube/ファイルなら サビにマーカー → A=サビ頭・B=サビ終わりで ABループ + 0.5x
4. 覚えたら 1x に戻して、カメラ+お手本PiPで自分の全身とタイミングをチェック
5. 現場は狭いので、家では「その場で収まる幅」もカメラで確認すると本番でぶつからない

地下芸練習・自分専用 ・ 公開/共有機能なし ・ データはすべてこの端末の localStorage のみ ・ YouTubeは公式IFrame API、Xは公式埋め込み(widgets.js)を使用
使い方・プライバシーポリシー

使い方

  1. YouTube / X のポストURLを貼って「読み込む」を押します（手持ちの動画ファイルも選べます）。読み込んだ動画は履歴に自動で保存され、次回からはタップだけで開けます。
  2. YouTube / 手持ちファイルは、スロー再生（0.25〜1.5倍）・ABループ・シーク・コマ送り・区間マーカーが使えます。BPMを指定するとカウント表示も出せます。
  3. X動画は公式埋め込みの仕様上、アプリ側からスローやループなどの再生操作はできません（左右反転・ズームは効きます）。
  4. カメラを鏡表示し、お手本を右下のPiPに重ねて録画・見比べができます（カメラは HTTPS で開いたときのみブラウザが許可します）。

プライバシーポリシー

  • 履歴・ライブラリ・区間マーカーは、この端末のブラウザ内（localStorage）にだけ保存されます（履歴は直近200件まで）。外部のサーバーへ送信されることはありません。
  • 動画の読み込みには、YouTube公式のIFrame APIとX公式の埋め込み（widgets.js）を使います。動画視聴に伴う通信は、各公式サービスの仕様によります。
  • カメラ映像は端末内でのみ表示・録画され、外部へ送信されることはありません。
  • このアプリ独自のアクセス解析・広告はありません。
