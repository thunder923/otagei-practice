# オタ芸練習アプリ

地下アイドル現場の**オタ芸**（サイリウム芸ではなく、いわゆる「地下芸」）を、お手本動画を見ながら練習するためのWebアプリです。YouTube / X のお手本動画と自分のカメラ映像を重ねて、動きとタイミングを確認できます。

**公開URL: https://thunder923.github.io/otagei-practice/**

## できること

- お手本動画の読み込み: YouTube / X のポストURL、手持ちの動画ファイル
  - YouTube検索、X「VideoStar オタ芸部」動画検索へのリンク付き
- **YouTube / 手持ちファイル**は細かい反復練習に対応
  - 再生速度変更（0.25x〜1.5x）
  - ABループ（A=区間の頭、B=区間の終わりを打って繰り返し）
  - シーク、コマ送り
  - 区間マーカー（イントロ / Aメロ / Bメロ / サビ / 落ちサビ / 間奏 / アウトロ / 技ポイント）
- **YouTube / X 共通**: 左右反転（背面から撮られた動画を自分の向きに合わせる）、ズーム（真ん中の人を拡大）
- カウント表示: BPMを指定して 1〜8 カウント表示＋クリック音（任意）
- カメラ練習: 自分のカメラを鏡表示し、お手本を右下にPiPで重ねて表示。そのまま録画して見比べたり、録画を保存したりできます
- **履歴・ライブラリ**: 1回読み込んだ動画は自動で履歴に保存され、次からはタップするだけ。曲名・グループ名・メモを後から付けると履歴側に反映されます（手動保存は不要）

## 使い方

1. 公開URLをブラウザで開く（カメラを使う場合は HTTPS で開いてください。公開URLはそのまま使えます）
2. YouTube / X のポストURLを貼って「読み込む」（手持ちファイルも選択可）
3. 練習したい区間にマーカーを置き、A/BボタンでABループ＋スロー再生で反復
4. 覚えてきたら等速に戻し、カメラ＋お手本PiPで全身とタイミングをチェック。録画して見比べると効果的です
5. 次回からは下の履歴をタップするだけで同じ動画を開けます

## X動画の制限（公式仕様）

Xの公式埋め込み（widgets.js）には再生操作APIがないため、アプリ側からスロー・ABループ・シーク・マーカー操作はできません（再生/停止は動画の真ん中をタップ）。左右反転・ズーム・PiP重ねは効きます。細かく繰り返したい区間は、YouTube版か手持ちファイルでの練習が確実です。

## データの扱い

- 履歴・ライブラリ・マーカーは、この端末のブラウザ内（localStorage）にだけ保存されます。履歴は直近200件まで
- 外部にデータが送信されることはありません。公開/共有機能もありません

## 注意事項

- カメラは HTTPS（または localhost）で開いた時のみブラウザが許可します
- 録画機能（MediaRecorder）に対応していないブラウザでは録画できません（iPhoneは最新のSafariでお試しください）
