# 地下芸練習アプリ（両方入り・自分専用）

Kanta本人専用・非公開。公開/共有は想定しない。サイリウム芸ではなく**地下芸（地下アイドル現場のオタ芸）想定**。

## 使い方
- `index.html` をブラウザで開く（カメラを使う場合のみ非公開のHTTPS置き場か localhost が必要。公開しないこと）
- YouTube / X のポストURLを貼って「読み込む」
  - YouTube検索 / X「VideoStar オタ芸部」動画検索へのリンク付き
- **1回読み込んだURLは自動で履歴に保存される**（localStorage、端末内のみ、直近200件）。再利用で最終利用日時と回数が更新され、先頭に来る
- 曲名・グループ名・メモは後から付けると履歴側に反映される（手動保存は不要）

## できること
- YouTube / 手持ち動画ファイル：速度変更（0.25–1.5x）、ABループ、シーク、コマ送り、区間マーカー（イントロ/Aメロ/Bメロ/サビ/落ちサビ/間奏/アウトロ/技ポイント）
- YouTube / X 共通：左右反転、ズーム（真ん中の人を拡大）
- カウント：BPM指定で 1–8 カウント表示＋クリック（任意）
- カメラ：鏡表示、お手本を右下PiPに重ねて表示、録画して見比べ＋保存

## X動画の制限（公式仕様）
Xの公式埋め込み（widgets.js createTweet）には再生操作APIがないため、
アプリ側からスロー・ABループ・シーク・マーカーはできない。再生/停止は動画タップ。
反転・ズーム・PiP重ねはCSS側で効く。細かい反復は YouTube版か手持ちファイル推奨。

## 注意
- カメラは HTTPS（または localhost）で開いた時のみブラウザが許可する
- データは外部送信なし。ライブラリ/マーカーは localStorage のみ
